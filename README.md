## 🎨 Visual Identity & Architecture

- **Color Palette:**
  - Background: Almost-black (`#08090D`)
  - Secondary Background / Surface: (`#10121A`)
  - Primary Accent: Electric Blue (`#4D8DFF`)
  - Secondary Accent: Neon Violet (`#9B6BFF`)
  - Text: Off-White (`#F5F5F7`)
  - Muted Text: Slate Grey (`#9296A5`)
- **Typography:** Plus Jakarta Sans, Space Grotesk, JetBrains Mono
- **Visual Design:** Cinematic lighting, selective glassmorphism, responsive editorial layout, custom magnetic cursor, and hardware-accelerated 3D spatial simulation.

---

## 🛠️ Tech Stack

- **Framework:** [React 18](https://react.dev/) + [Vite 6](https://vitejs.dev/)
- **Styling:** [Tailwind CSS 3](https://tailwindcss.com/)
- **Animation & Micro-interactions:** [Framer Motion](https://www.framer.com/motion/)
- **3D Spatial Environment:** [Three.js](https://threejs.org/)
- **Icons:** Custom SVG components + [Lucide React](https://lucide.dev/)
- **Interactive FX:** [Canvas Confetti](https://github.com/catdad/canvas-confetti)
- **Deployment:** GitHub Pages via GitHub Actions CI/CD & `gh-pages`

## 💻 Local Development Setup

To run this portfolio locally:

```bash
# 1. Clone the repository
git clone https://github.com/murasolib/murasolib.github.io.git
cd murasolib.github.io

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Open in browser
# http://localhost:5173
```

---

## 🔨 Production Build & Deployment

### Automated Deployment (GitHub Actions)
Any commit pushed to the `main` branch automatically triggers the `.github/workflows/deploy.yml` workflow, which builds the bundle and deploys it live to **GitHub Pages**.

### Manual One-Command Deployment
Alternatively, publish directly using the `gh-pages` utility:

```bash
npm run deploy
```
